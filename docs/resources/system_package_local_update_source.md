# routeros_system_package_local_update_source (Resource)
*<span style="color:red">This resource requires a minimum version of RouterOS 7.17.</span>*

A local-update client takes its `.npk` files from the sources listed in this menu instead of from MikroTik's download servers. The transfer runs over WinBox rather than HTTP or FTP, so the source router has to answer WinBox on the address given here and the account named has to exist on that router, not on this one.

The password is the reason the resource exists, and it is also the field most likely to churn a plan. RouterOS hides stored secrets from an account that does not carry the `sensitive` policy, so a provider account without it reads the entry back with a mask in place of the password, and the mask lands in the state. A declared `password` is then compared against the mask on every plan, and each apply writes the real password again. That is left in place on purpose: a suppression wide enough to swallow the mask would swallow a genuine rotation as well, and a rotation that silently never reaches the device is the worse failure. Give the provider account the `sensitive` policy for a quiet plan.

An entry whose configuration declares no `password`, such as an imported one, is kept out of the plan, and nothing is written for its password either: the provider never sends back an unchanged sensitive value that configuration does not declare. Changing the entry's `user` or `address` leaves the credential on the source router as it was.

---

## Example Usage
```terraform
resource "routeros_system_package_local_update_source" "hub" {
  address  = "192.168.88.1"
  user     = "package-source"
  password = var.package_source_password
}
```

## Schema

### Required

- `address` (String) Address of the router that serves the packages. The client opens a WinBox connection to it, so the source router has to answer WinBox on this address and let this client reach it.

### Optional

- `password` (String, Sensitive) Password of the account the client authenticates to the package source with.
- `user` (String) Name of the account the client authenticates to the package source with. It is an account on the source router, and reading that router's file list is all it has to be able to do.

### Read-Only

- `id` (String) The ID of this resource.
