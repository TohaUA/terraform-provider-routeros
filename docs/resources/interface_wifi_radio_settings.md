# routeros_interface_wifi_radio_settings (Resource)
Manage `/interface/wifi/radio/settings`. Requires RouterOS 7.25.1 or later and the corresponding hardware/package. [CLI reference](https://manual.mikrotik.com/docs/7.25/cli-reference/interface/wifi/radio/settings/). Deleting the Terraform resource leaves the settings on the router. Import using any non-empty ID.

## Example Usage
```terraform
# Device-specific settings; use only on hardware supporting these controls.
resource "routeros_interface_wifi_radio_settings" "settings" {
  external_antenna = false
  wifi_band        = "5GHz"
}
```
