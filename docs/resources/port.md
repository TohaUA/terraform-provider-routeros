# routeros_port (Resource)
Manage `/port`. Requires RouterOS 7.25.1 or later and the corresponding hardware/package. [CLI reference](https://manual.mikrotik.com/docs/7.25/cli-reference/port/). Manages an existing hardware entry by name; deleting the Terraform resource only forgets it.

## Example Usage
```terraform
# RouterOS 7.25.1+. Check the menu's package and hardware requirements.
# Manages an existing entry. Destroy only forgets Terraform state.
resource "routeros_port" "example" {
  name         = "serial0"
  baud_rate    = "115200"
  flow_control = "none"
}
```
