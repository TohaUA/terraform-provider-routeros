# routeros_interface_ethernet_poe (Resource)
Manage `/interface/ethernet/poe`. Requires RouterOS 7.25.1 or later and the corresponding hardware/package. [CLI reference](https://manual.mikrotik.com/docs/7.25/cli-reference/interface/ethernet/poe/). Manages an existing hardware entry by name; deleting the Terraform resource only forgets it.

## Example Usage
```terraform
# RouterOS 7.25.1+. Check the menu's package and hardware requirements.
# Manages an existing entry. Destroy only forgets Terraform state.
resource "routeros_interface_ethernet_poe" "example" {
  name         = "ether5"
  poe_out      = "auto-on"
  poe_priority = 10
}
```
