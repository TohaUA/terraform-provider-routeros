# routeros_system_ptp_port (Resource)
Manage `/system/ptp/port`. Requires RouterOS 7.25.1 or later and the corresponding hardware/package. [CLI reference](https://manual.mikrotik.com/docs/7.25/cli-reference/system/ptp/port/).

## Example Usage
```terraform
# RouterOS 7.25.1+. Check the menu's package and hardware requirements.
resource "routeros_system_ptp_port" "example" {
  ptp       = routeros_system_ptp.example.name
  interface = "ether4"
  role      = "slave"
  vlan_id   = 100
  disabled  = true
}

resource "routeros_system_ptp" "example" {
  name     = "site-clock"
  disabled = true
}
```
