# routeros_interface_ethernet_pon (Resource)
Manage `/interface/ethernet/pon`. Requires RouterOS 7.25 or later and the corresponding hardware/package. [CLI reference](https://manual.mikrotik.com/docs/7.25/cli-reference/interface/ethernet/pon/). Manages an existing hardware entry by name; deleting the Terraform resource only forgets it.

## Example Usage
```terraform
# RouterOS 7.25+. Check the menu's package and hardware requirements.
# Manages an existing entry. Destroy only forgets Terraform state.
resource "routeros_interface_ethernet_pon" "example" {
  name        = "pon1"
  olt_max_mtu = 1500
}
```
