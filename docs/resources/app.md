# routeros_app (Resource)
Manage a custom App on RouterOS 7.25.1 with the container package and container device mode enabled. Disabled by default. Enabling starts deployment asynchronously; status and running expose progress. Destroy removes the custom definition using /app/remove; cleanup is a separate explicit action. YAML, environment, and secrets remain in Terraform state. [Apps documentation](https://manual.mikrotik.com/docs/7.25/containers/apps/).

## Example Usage
```terraform
resource "routeros_app" "worker" {
  # Set false to begin asynchronous image download and startup.
  disabled  = true
  network   = "internal"
  use_https = false
  yaml = yamlencode({
    name = "example-worker"
    services = {
      worker = {
        image   = "docker.io/library/alpine:3.22"
        command = ["/bin/sh", "-c", "while true; do sleep 60; done"]
        environment = {
          ROUTER = "[networkRouterIP]"
        }
      }
    }
  })
}
```
