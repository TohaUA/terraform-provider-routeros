# routeros_app_cleanup (Resource)
Execute `/app/cleanup` on RouterOS 7.25.1+. Runs on creation or configuration/trigger changes. Refresh does not execute it; deletion only removes state and cannot undo the command. [CLI reference](https://manual.mikrotik.com/docs/7.25/cli-reference/app/cleanup/).

## Example Usage
```terraform
# Define routeros_app.worker as in the routeros_app example.
# Cleanup permanently removes downloaded images and App data.
# Disable the App before requesting cleanup.
resource "routeros_app_cleanup" "worker" {
  numbers = routeros_app.worker.id
  triggers = {
    request = "cleanup-1" # Change only when another cleanup is intended.
  }
}
```
