# routeros_mac_bootstrap (Resource)
Bootstraps initial IPv4 addressing and HTTPS REST (`www-ssl`) TLS access on an unaddressed MikroTik RouterOS device over layer-2 MAC-Telnet, then verifies `/rest/system/resource` over pinned TLS. Intended only for Stage 1 initial provisioning on trusted, isolated segments.

~> **Security warning:** Although MAC-Telnet uses EC-SRP5 to protect credentials during login, the post-login terminal session is **cleartext with no server authentication**. Only run `routeros_mac_bootstrap` on a trusted, isolated layer-2 bench or provisioning VLAN, rotate the admin password over TLS afterward if `expected_tls_fingerprint` was not pinned out-of-band, and lock down MAC services in Stage 2. See the [Layer-2 MAC bootstrap security guide](../guides/l2_mac_bootstrap_security.md).

---

## Example Usage
```terraform
provider "routeros" {}

variable "bootstrap_password" {
  type      = string
  sensitive = true
  ephemeral = true
  default   = ""
}

resource "routeros_mac_bootstrap" "initial" {
  interface           = "eth0"
  mac_address         = "54:05:AB:01:02:03"
  address             = "192.168.88.1/24"
  target_interface    = "ether2"
  username            = "admin"
  password_wo         = var.bootstrap_password
  password_wo_version = 1
  allow_insecure_l2   = true
}
```

## Schema

### Required

- `address` (String) IPv4 CIDR address to assign on `target_interface` (for example `192.168.88.1/24`).
- `allow_insecure_l2` (Boolean) Explicit acknowledgement that post-login MAC-Telnet traffic is cleartext with no server authentication. Must be `true` to run bootstrap.
- `interface` (String) Local host network interface connected to the target layer-2 segment.
- `mac_address` (String) Target RouterOS interface MAC address.
- `target_interface` (String) RouterOS interface name to assign `address` to (for example `ether2` or `bridge`).
- `username` (String) RouterOS username used to authenticate the MAC-Telnet session.

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `certificate_name` (String) Name of the self-signed TLS server certificate created on RouterOS if absent.
- `enable_api_ssl` (Boolean) Whether to also enable `/ip/service` `api-ssl` with the bootstrap certificate.
- `expected_tls_fingerprint` (String) Optional expected SHA-256 leaf certificate fingerprint obtained out-of-band. When set, bootstrap fails closed if the router returns a different fingerprint.
- `password` (String, Sensitive) Legacy RouterOS password for MAC-Telnet authentication (stored in state; prefer `password_wo`).
- `password_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) Write-only RouterOS password for MAC-Telnet authentication (Terraform 1.11+, omitted from state and plans). Increment `password_wo_version` to force replacement.
- `password_wo_version` (Number) Increment this value to force replacement when updating `password_wo`.
- `timeout` (String) Bootstrap timeout as a Go duration string (for example `30s`).

- `identity` (String) RouterOS system identity reported by the bootstrapped router.
- `router_address` (String) Bootstrapped IPv4 host address (without CIDR prefix) verified over pinned HTTPS REST.
- `routeros_version` (String) RouterOS version string reported by the bootstrapped router.
- `tls_fingerprint` (String) Normalized uppercase SHA-256 fingerprint of the router's verified TLS certificate.
