# routeros_system_device_mode (Data Source)


Reads `/system/device-mode` on the configured RouterOS device so deployments can inspect the active device mode and feature permissions (such as `scheduler` and `fetch`). Unavailable attributes are left `null` and absent from `features`, distinct from an explicit `false`. Changing device mode settings and their physical confirmation are outside this data source.

---

## Example Usage
```terraform
data "routeros_system_device_mode" "current" {}

output "device_mode_summary" {
  value = {
    mode                 = data.routeros_system_device_mode.current.mode
    scheduler_allowed    = data.routeros_system_device_mode.current.scheduler == true
    fetch_explicit_false = data.routeros_system_device_mode.current.fetch == false
    fetch_unavailable    = data.routeros_system_device_mode.current.fetch == null
    features             = data.routeros_system_device_mode.current.features
  }
}
```
