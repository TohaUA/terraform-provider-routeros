# routeros_ip_neighbor (Data Source)


Reads live neighbor discovery entries from `/ip/neighbor` over the configured provider transport. Returned records are point-in-time observations of neighbors seen by the target router (rather than local host layer-2 discovery) and are best used in standalone inventory or post-change verification workspaces.

---

## Example Usage
```terraform
data "routeros_ip_neighbor" "all" {
  filter = {
    interface = "ether2"
  }
}

output "neighbor_identities" {
  value = [
    for n in data.routeros_ip_neighbor.all.neighbors : {
      interface      = n.interface
      identity       = n.identity
      interface_name = n.interface_name
      mac_address    = n.mac_address
      discovered_by  = n.discovered_by
    }
  ]
}
```
