# routeros_interface_wifi_monitor (Data Source)
Read `/interface/wifi/monitor` on RouterOS 7.25.1+. [CLI reference](https://manual.mikrotik.com/docs/7.25/cli-reference/interface/wifi/monitor/). Uses once to read a finite snapshot, including MLD link ID, channel/puncturing display, and AFC status when the driver exposes them. Select an interface with arguments = { numbers = "wifi1" }.

## Example Usage
```terraform
data "routeros_interface_wifi_monitor" "wifi1" {
  arguments = {
    numbers = "wifi1"
  }
}

# Reads one snapshot. Driver-dependent outputs include mld_link_id,
# channel (including puncturing markers), and afc_status.
```
