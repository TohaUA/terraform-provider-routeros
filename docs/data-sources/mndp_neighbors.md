# routeros_mndp_neighbors (Data Source)
Discovers MikroTik RouterOS devices on a local layer-2 network segment via MNDP (UDP/5678) without requiring an IP address on the router.

Sends MikroTik Neighbor Discovery Protocol (MNDP) probes over UDP port `5678` bound to the specified local interface and returns deduplicated neighbors sorted by `mac_address`.

~> **Security note:** MNDP announcements are unauthenticated broadcasts and can be spoofed on shared networks. Use only on trusted, isolated provisioning segments. See the [Layer-2 MAC bootstrap security guide](../guides/l2_mac_bootstrap_security.md).

---

## Example Usage
```terraform
provider "routeros" {}

data "routeros_mndp_neighbors" "lab" {
  interface = "eth0"
  timeout   = "5s"
}

output "discovered_neighbors" {
  value = data.routeros_mndp_neighbors.lab.neighbors
}
```
