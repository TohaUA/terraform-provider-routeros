# routeros_interface_bridge_host (Data Source)


Reads live bridge MAC-to-port host entries from `/interface/bridge/host` over the configured provider transport. Returned records are point-in-time observations of the router's dynamic and local bridge host table and are best used in standalone inventory or post-change verification workspaces.

---

## Example Usage
```terraform
data "routeros_interface_bridge_host" "bridge" {
  filter = {
    bridge = "bridge"
  }
}

output "bridge_mac_table" {
  value = [
    for h in data.routeros_interface_bridge_host.bridge.hosts : {
      bridge      = h.bridge
      interface   = h.interface
      vid         = h.vid
      mac_address = h.mac_address
      dynamic     = h.dynamic
    }
  ]
}
```
